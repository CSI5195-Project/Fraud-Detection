In order to obtain model 2, the notebooks were ran in the following order:
1. hyperparameter_optimization.ipynb was used to generate 10 trials with varying hyperparameters as dictated by the TPE sampler. The results of this notebook can be found under model2_optimization_results.
2. get-best-hyperparams.ipynb used the output generated by the previous notebook to select the best hyperparameter combination out of the 10 trials. The selected combination can be found under model_2_hyperparameters_selected.json
3. ssn-fraud-detection-model-2-2 is used to run 10 trials of model 2 with the selected set of hyperparameters. The results are saved under model2_output_10_trials.
4. ssn-fraud-detection-model-2-3 is a variation of the previous notebook were the model is run for 1 trial and the train and test splits are saved alongside the output in order to be used for the explainability analysis. The results of this notebook are saved under model2_ouput_1_trial.
